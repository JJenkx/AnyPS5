- [sceNpAuthGetAuthorizedAppCode](../../../core/libs/prx/libSceNpAuth/Export.cpp) (libSceNpAuth) - declared without parameters as a throwing stub; Minecraft (PPSA17221) imports it and fails to load without it. - [sceNpAuthGetAuthorizationCodeV3, sceNpAuthGetIdTokenV3, sceNpAuthPollAsync, sceNpAuthWaitAsync](../../../core/libs/prx/libSceNpAuth/Export.cpp) (libSceNpAuth) - request tracking, `REQUEST_NOT_FOUND` (0x80550306), `INVALID_ID` (0x80550307) for non-async or unprocessed requests, and auth `INVALID_ARGUMENT` (0x80550301) follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/e0a466753a1aacbc8db8253be685bf7ab4d9daae/src/core/libraries/np/np_auth.cpp) and its [error codes](https://github.com/shadps4-emu/shadPS4/blob/e0a466753a1aacbc8db8253be685bf7ab4d9daae/src/core/libraries/np/np_error.h) (PS4). Poll and Wait reject a null output; a repeated token or code submission stores INVALID_ARGUMENT for later Poll/Wait calls. Async submissions return OK and store SIGNED_OUT; sync submissions return SIGNED_OUT immediately. No network authentication is performed. PS5 behavior is unverified. Request IDs remain monotonically increasing host handles without the reference's active-request limit; async creation parameters and token/code parameter fields are not validated, AbortRequest has no effect, and DeleteRequest succeeds for unknown IDs.
